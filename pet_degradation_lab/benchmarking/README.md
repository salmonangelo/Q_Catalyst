# Benchmarking Module (Milestone 3 Architecture)

Defines experimental validation protocols and literature comparative studies:

- `experimental_data/`: Curation of published kinetic measurements ($k_{cat}$, $K_M$, specific activity on amorphous film and microplastics).
- `reference_comparison/`: Side-by-side benchmarking against known benchmark engineered variants (FAST-PETase, DuraPETase, HotPETase, ThermoPETase).
- `validation/`: Statistical correlation between computed mechanistic descriptors / simulation metrics and experimental degradation rates.
